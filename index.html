Machine Learning for Big Data


Instructor: Dr. Gerit Wagner

Welcome to Machine Learning for Big Data. This course introduces machine learning as a core part of data science for big data contexts, where analysts work with large, high-dimensional, and diverse datasets. Throughout the semester, you will learn how modern machine learning methods complement classical statistics, how to prepare and explore data, and how to build models for classification, prediction, and managerial decision support. The course combines lectures, in-class and home exercises, and practical work with R to help you connect methods and algorithms to real analytical problems.
